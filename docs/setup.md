# 설치·실행 가이드

> 인증키 설정, 실행 방법, 실행 오류별 해결 · [← README로 돌아가기](../README.md)

## 인증키 설정 (KEY.env)

세 가지 용어를 구분하면 쉽습니다.

| 용어 | 뜻 | 예 |
|---|---|---|
| `KEY.env` | 설정을 저장하는 **파일 이름** | `server.py` 옆에 있는 텍스트 파일 |
| `KMA_SERVICE_KEY` | 그 파일 안에 적는 **설정 이름** | 항상 이 이름 그대로 |
| 인증키 | 공공데이터포털에서 받은 **실제 값** | 사람마다 다른 긴 문자열 |

### 저장 위치

`KEY.env`는 `server.py`, `서버실행.cmd`와 **같은 폴더**(프로젝트 루트)에 둡니다.

```text
kma-mid-forecast/
├── server.py
├── 서버실행.cmd
└── KEY.env   ← 여기
```

서버를 실행하면 첫 화면과 터미널에 실제 경로가 표시됩니다.

### 작성 형식

파일 안에 다음 한 줄을 저장합니다. 따옴표나 공백 없이 `=` 뒤에 키를 붙입니다.

```text
KMA_SERVICE_KEY=발급받은_실제_인증키
```

- 공공데이터포털의 **일반 인증키(Decoding)** 를 권장합니다. `%2B`처럼 `%`가 들어간 **Encoding** 키를 넣어도 서버가 한 번만 해독해 사용하므로 이중 인코딩되지 않습니다.
- 키 안의 `+` 문자는 공백으로 바뀌지 않습니다.
- UTF-8, UTF-8 BOM(메모장 저장 방식), 빈 줄, `#` 주석을 처리합니다. 파일 내용은 코드나 명령으로 실행하지 않고 글자로만 읽습니다.
- `KEY.env.example`은 예시 파일이며 `KMA_SERVICE_KEY=YOUR_API_KEY` 자리표시자만 들어 있습니다. 복사해서 `KEY.env`로 이름을 바꾼 뒤 값을 바꿔도 됩니다.

### Windows에서 KEY.env.txt가 되지 않게 하기

1. 메모장 → 다른 이름으로 저장 → 파일 형식을 **모든 파일 (\*.\*)** 로 바꾸고, 파일 이름에 `KEY.env` 입력, 인코딩 UTF-8.
2. 파일 탐색기 → 보기 → 표시 → **파일 확장명** 체크. 이름이 `KEY.env.txt`로 보이면 `KEY.env`로 바꿉니다.
3. 명령 프롬프트에서 확인: `dir KEY.env*` → `KEY.env`만 보여야 합니다.

서버도 `KEY.env.txt`를 발견하면 터미널과 화면에 이름을 바꾸라고 안내합니다.

### 우선순위와 재시작

1. 운영체제(또는 배포 서비스)의 환경변수 `KMA_SERVICE_KEY`에 값이 있으면 그 값을 사용합니다.
2. 환경변수가 없거나 공백뿐이면 `KEY.env`를 사용합니다.
3. `.env` 등 다른 파일은 읽지 않습니다(설정 충돌 방지). `.env`가 있으면 KEY.env로 옮기라고 안내만 합니다.

설정은 **서버 시작 시 한 번** 읽습니다. `KEY.env`를 만들거나 바꾸면 서버 창에서 `Ctrl+C`로 종료하고 다시 실행해야 반영됩니다. Windows 환경변수를 바꿨다면 새 명령 프롬프트 창에서 실행해야 합니다.

### 인증키가 없다면

1. 공공데이터포털에서 [기상청_중기예보 조회서비스](https://www.data.go.kr/data/15059468/openapi.do)와 **기상청_단기예보 조회서비스**를 각각 **활용신청**합니다. 일반 인증키 하나(`KMA_SERVICE_KEY`)로 두 서비스를 모두 씁니다.
2. 마이페이지 → 개발계정에서 승인된 서비스의 **일반 인증키**를 확인합니다.
3. 키는 대화창·메신저에 붙여넣지 말고 `KEY.env`(또는 배포 서비스의 비밀 환경변수)에만 직접 입력합니다.

이 앱은 활용신청 승인 여부를 미리 확인할 수 없습니다. 실제 호출 결과로만 알 수 있습니다(응답 코드 20·30·31 등은 "인증·활용신청 오류"로 표시).

### 비노출

- 인증키는 서버에서만 사용하며 브라우저 코드, 화면, 터미널 로그, 오류 메시지, 캐시 DB에 남기지 않습니다. 로그에는 요청 경로만 남기고 쿼리는 남기지 않습니다.
- 기상청 요청 URL에는 키가 들어 있으므로 네트워크 오류 원문은 버리고 분류된 메시지만 보여 줍니다.
- `.gitignore`에 `KEY.env`, `KEY.env.txt`, `.env`, `runtime/`이 포함되어 있고, 배포 ZIP에도 넣지 않습니다.

## 실행 방법

### 필요한 환경

- Python **3.10 이상** (https://www.python.org/downloads/). Windows 설치 첫 화면에서 **Add python.exe to PATH**를 체크합니다.
- 인터넷 연결(기상청 API 호출용). 추가 패키지는 없습니다.

### Windows: 서버실행.cmd

1. `서버실행.cmd`를 더블클릭합니다. 명령 프롬프트에서 다른 폴더에 있어도 `"C:\경로\kma-mid-forecast\서버실행.cmd"`처럼 실행할 수 있습니다.
2. 파일이 자기 위치로 이동한 뒤 `py -3` → `python` 순서로 Python 3.10 이상을 찾습니다.
3. 터미널에 `[준비 완료] 브라우저에서 http://127.0.0.1:8080/now 에 접속하세요.`가 나오면 접속합니다. 이 문장은 서버가 실제로 응답하는지 스스로 확인한 뒤에만 출력됩니다.
4. 서버는 이 창에서 실행됩니다. **창을 닫으면 서버가 꺼집니다.** 종료는 `Ctrl+C`(일괄 작업 종료 질문에는 `Y`).

한글·공백이 들어간 경로도 따옴표로 처리합니다. 오류가 나면 창이 바로 닫히지 않고 메시지를 보여 줍니다.

### macOS·Linux 또는 터미널에서 직접

```bash
cd kma-mid-forecast
```

```bash
python3 server.py
```

다른 폴더에서 `python3 "/전체/경로/server.py"`로 실행해도 `KEY.env`와 데이터 폴더를 `server.py` 위치 기준으로 찾습니다. 다른 포트: `python3 server.py --port 8081`.

### 서버 준비 상태 확인

- 터미널의 `[준비 완료]` 문장
- 브라우저에서 `http://127.0.0.1:8080/api/health` → `{"ok": true}`
- `http://127.0.0.1:8080/api/status` → 인증키 상태(값 없이), 호출량, 발표시각 후보

### 실행 오류별 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 브라우저 "사이트에 연결할 수 없음" | 서버가 실행되지 않음(창을 닫음) | `서버실행.cmd` 다시 실행, `[준비 완료]` 확인. **인증키 문제가 아닙니다.** |
| `[오류] server.py를 찾을 수 없습니다` | cmd 파일만 다른 곳으로 옮김 | cmd와 server.py를 같은 폴더에 둠 |
| `[오류] Python 3을 찾을 수 없습니다` / `3.10 이상이 필요` | Python 미설치·구버전·PATH 미등록 | python.org에서 설치(Add to PATH 체크) 후 창을 새로 열기 |
| `[오류] 8080 포트를 다른 프로그램이 이미 사용 중` | 이미 서버가 다른 창에서 실행 중이거나 다른 프로그램 | 기존 창 확인. 프로그램을 임의로 종료하지 않음. `--port 8081`로 실행 가능 |
| 화면 "인증키 설정 필요" | KEY.env 없음/빈 값/자리표시자 | 위 "인증키 설정" 참고 후 서버 재시작 |
| "[인증·활용신청 오류]" | 키 오타, 활용신청 미승인, 기한 만료 등 | 포털에서 승인 상태와 키 확인 |
| "[네트워크·제공기관 연결 오류]" | 인터넷 끊김, 기상청 서버 문제 | 연결 확인. 재시도 간격이 30초→최대 15분으로 늘어남 |
| "[제공기관 호출 제한]" | 포털 일일 한도 초과(코드 22) | 앱이 1시간 동안 외부 호출 중지, 캐시만 표시 |
| "조회 대기 중" (파란 안내) | 30초 공통 호출 간격 대기 | 오류 아님. 자동으로 조회됨 |
| 업데이트 후 옛 화면이 보임 | 브라우저 캐시 | `Ctrl+F5`(맥 `Cmd+Shift+R`) 한 번 |
