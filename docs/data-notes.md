# 데이터 해석 노트

> 기상청 응답 필드 해석과 문서·실제 응답의 차이 · [← README로 돌아가기](../README.md)

## 중기예보 데이터 해석

- `tmFc`는 `YYYYMMDDHHmm` 형식의 **발표시각**이며 예보 날짜가 아닙니다. 가이드 기준 최근 24시간 발표본만 조회할 수 있어 선택지는 최근 06시·18시 두 개입니다.
- 응답에는 발표시각 필드가 없습니다. 화면의 발표시각은 "요청에 사용한 값"으로 따로 보관한 것입니다.
- 06시 발표: 4~10일 후, 18시 발표: 5~10일 후(실제 응답으로 확인, 18시 응답에는 4일 후 필드가 아예 없음).
- 필드 이름의 숫자(예: `wf5Am`의 5)는 **발표일 기준 N일 후**로 해석해 실제 달력 날짜로 표시합니다.
- 4~7일 후는 오전(`Am`)·오후(`Pm`), 8~10일 후는 하루 단위입니다. 하루 단위 값을 오전·오후로 복제하지 않습니다.
- `rnSt5Am`(강수확률, %)과 `wf5Am`(날씨)은 같은 날짜·오전으로 묶습니다. 강수확률은 강수량(mm)이 아닙니다.
- `taMin5`/`taMax5`는 같은 날짜의 예상 최저/최고기온(℃)입니다. 관측값이 아닙니다.
- 해상 `wh5AAm`은 5일 후 오전 **최저** 예상파고, `wh5BAm`은 **최고** 예상파고(m), `wh8A`/`wh8B`는 8일 후 하루 단위 최저/최고입니다.
- 없는 필드·빈 문자열은 0이 아니라 "미제공"으로 표시하고 그래프에서 보간하지 않습니다. 실제 0(예: 예상 최저기온 0℃)은 그대로 표시합니다.
- API `totalCount`는 응답 항목 수(보통 1)이고, 한 항목 안의 여러 날짜를 펼친 그래프 행 수와 다릅니다.
- 기온의 `Low`·`High` 범위 필드는 실제 응답에 0~3 정도의 값으로 들어오지만, 절대 기온인지 기준값과의 차이인지 공식 문서에서 확인하지 못해 그래프에 쓰지 않습니다(원문 필드 보기에서 확인 가능).
- 전망문(`wfSv`)은 원문 줄바꿈 그대로 보여 주며 수치 그래프로 바꾸지 않습니다. 응답에 지점번호가 없어 요청·응답 코드는 "비교 불가"로 표시합니다.
- API에서 받은 문자열은 HTML로 실행하지 않고 글자로만 표시합니다.

### 첨부 자료에서 확인한 차이

- 가이드 예제 URL은 `http://`이지만 실제로 `https://apis.data.go.kr`가 동작함을 확인해 HTTPS를 사용합니다.
- 기온 예제 XML의 `taMax8Min`·`taMin8Min`은 명세의 `taMax8Low`·`taMin8Low`와 다릅니다. 실제 응답(2026-11-10)은 명세대로 `Low`를 사용했습니다.
- 육상 응답 명세는 `regid`(소문자), 예제와 실제 응답은 `regId`입니다. 둘 다 처리합니다.
- Excel 범례(E·F열)는 "A=도시(지역)", "C=육상"으로 적혀 있지만, 실제 행은 A가 광역 구역(11B00000 등), C가 도시 지점(서울 11B10101 등)이며 가이드 기온 표와 C 코드가 일치합니다. 그래서 C 코드 203개를 기온 지역으로 사용했습니다.
- Excel의 같은 이름 지점(광주 2곳, 고성 2곳)은 코드가 달라 선택 목록에 코드를 함께 표시합니다.

## 단기 기능(현재 날씨·6시간 예보·단기예보)

가이드: `단기예보조회서비스_API활용가이드_261019.docx`, 격자 좌표: `…격자_위경도(2610).xlsx`(최종 업데이트 20260930).

### 발표 주기와 조회 시각
| 기능 | 발표 | 호출 가능 시각 | 내용 |
|---|---|---|---|
| 현재 날씨(초단기실황) | 매시 정시, 10분마다 갱신 | 정시 +10분 이후 | 대표 AWS **관측값**(기온 T1H, 강수 RN1, 습도 REH, 풍속 WSD, 풍향 VEC, 강수형태 PTY 등) |
| 6시간 예보(초단기예보) | 매시 30분, 10분마다 갱신 | 30분 발표 +15분(45분) 이후 | 앞으로 6시간 시간별 예보(하늘상태·강수확률 포함) |
| 단기예보 | 02·05·08·11·14·17·20·23시 | 발표 +10분 이후 | 며칠 앞까지 시간별 예보와 일 최저·최고기온 |

화면의 발표본 선택지는 "최신"과 "직전 발표"입니다. 최신본이 아직 없으면(코드 03) 직전 발표본을 보여 주며, 시간이 지나 새 발표본이 생기면 직접 고르지 않은 경우 자동으로 최신으로 옮깁니다.

### 지역(격자)
- 지역 목록은 격자 Excel의 시도·시군구·읍면동 3,838곳이며(`data/grid_regions.json`), 변환 스크립트는 `tools/build_grid_regions.py`입니다. Excel이 갱신되면 `python3 tools/build_grid_regions.py "격자_위경도.xlsx"`로 다시 만듭니다.
- 같은 격자(X,Y)를 쓰는 지역은 **같은 값**을 받습니다(서버 캐시도 격자 단위로 공유). 행정동 단위의 정밀 예보가 아니며, 화면에 "같은 격자를 쓰는 지역 N곳"을 표시합니다.
- 파일의 `전남광주통합특별시`, `이어도`는 Excel에 있는 그대로입니다.

### 값 해석
- 하늘상태 SKY: 1 맑음, 3 구름많음, 4 흐림. 강수형태 PTY: 0 없음, 1 비, 2 비/눈, 3 눈, 4 소나기(초단기는 5 빗방울, 6 빗방울눈날림, 7 눈날림). 아이콘은 이 코드값으로 고릅니다.
- 현재 날씨(실황)에는 하늘상태가 없으므로 맑음·흐림 아이콘을 만들지 않습니다(강수가 있을 때만 강수 아이콘).
- 풍향은 바람이 불어오는 방향이며 기상청 변환식 (풍향 + 22.5×0.5) / 22.5 의 소수점 이하를 버려 16방위로 바꿉니다(예: 339° → 북북서풍). 화면의 화살표는 바람이 향하는 쪽입니다.
- 결측값(±900 이상, 빈 값)은 0이 아니라 '미제공'으로 표시하고, 유효한 0은 그대로 보여 줍니다.
- 단기예보 후반(글피 등)은 **3시간 간격**이고 강수량(PCP)·적설(SNO)·풍속(WSD)이 숫자가 아니라 코드값(약한 비·보통 비·강한 비, 보통 눈·많은 눈, 약한 바람·약간 강한 바람·강한 바람)입니다. 이 앱은 직전 시각과 간격이 1시간보다 큰 시각을 코드값으로 해석합니다(실제 응답에서 11/16 00시는 숫자, 03시부터 코드값임을 확인).
- 오늘의 최저기온(TMN)은 02시 발표본에만 있습니다. 08시 발표본 등에서는 '미제공'으로 표시합니다. 날짜별 카드의 하늘상태는 낮 12시 값이며 하루 대표값이 아닙니다.
- 파고(WAV)는 해상 격자에만 값이 있으며 육지는 0으로 내려옵니다(표시하지 않음).

### 문서와 실제 응답의 차이(확인한 것)
- 가이드 예시 주소는 `apihub.kma.go.kr` + `authKey`이지만, 공공데이터포털 주소 `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0` + `serviceKey`로 세 기능 모두 정상 응답했습니다. 이 앱은 후자를 씁니다.
- 가이드의 풍속 코드 설명 중 "약한 바람: 4m/s 이상"은 앞뒤가 맞지 않아 풍속 수치 기준은 표시하지 않고 용어만 표시합니다.
- 초단기예보 시각표에 오타(19시 Base_time `19030`, 20시 행의 예보시간 중복)가 있습니다. 이 앱은 규칙(매시 30분)으로 계산합니다.
