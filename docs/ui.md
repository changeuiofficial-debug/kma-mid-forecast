# 화면 구성과 표시 규칙

> 조회 결과 화면, 드롭다운, 날짜 표기, 중기전망 요약 규칙 · [← README로 돌아가기](../README.md)

## 조회 결과 화면 구성

| 페이지 | 구성 |
|---|---|
| 공통 | 발표·기간·코드 비교를 칩 한 줄로 요약, 응답 값 중 최댓값·최솟값을 고른 요약 카드 3개, 상세 설명은 '조회 정보 자세히' 아코디언, 그래프와 수치표는 탭으로 전환 |
| 중기전망 | 맨 위에 비·기온·해상 3줄 요약(원문에 적힌 날짜·지역·기온·파고만 옮김, 칩 없이 줄맞춤). 요약에 담기지 않는 주제(주말전망·변동성 등)와 원문 전체는 '자세히 보기' 목록에서 한 줄씩 눌러 원문을 봄 |
| 육상예보 | 날짜별 타임라인(오전·오후 / 하루) + 날씨 아이콘 + 강수확률 게이지, 강수확률 막대그래프 |
| 기온 | 날짜별 '최저~최고' 범위 막대(파랑→주황) 그래프 |
| 해상예보 | 날짜별 타임라인 + 날씨 아이콘 + 예상파고 범위 막대. 1.5m·3m 색 구분은 이 앱의 표시 기준이며 공식 특보 기준이 아님 |

- 날씨 아이콘은 가이드 '하늘상태' 문구(맑음, 구름많음, 흐림 및 비·눈·비/눈·소나기 조합)와 정확히 같을 때만 표시하고, 원문 글자를 항상 함께 둡니다. 목록에 없는 문구에는 아이콘을 붙이지 않습니다.
- 그래프에서 날짜 칸에 마우스를 올리거나 터치하면 안내선과 값 말풍선이 나옵니다.
- 움직임(나타나기, 막대 자라기, 숫자 올라가기)은 처음 표시·지역 변경·새 발표 자료 반영 때만 실행됩니다. 30초 자동 확인에서 값이 같으면 화면을 다시 그리지 않아 선택한 탭과 열린 아코디언이 유지됩니다.
- 운영체제의 '동작 줄이기' 설정을 켜면 모든 애니메이션이 꺼집니다.
- 쓰지 않은 효과(커서 효과, 3D 틸트, 마키, 타이핑·스크램블 텍스트, 패럴렉스 등)는 정보 읽기에 도움이 되지 않거나 숫자를 늦게·흐리게 보여 주므로 제외했습니다.

## 지역·발표시각 선택(드롭다운)

브라우저 기본 `<select>`는 펼쳐진 목록을 CSS로 꾸밀 수 없어서, 화면용 드롭다운(`static/combo.js`)을 얹었습니다. 원래 `<select>`는 화면에서만 숨기고 값 저장소로 남겨 두었기 때문에, 지역 저장·챗봇의 지역 선택·이전 발표본 자동 전환 같은 기존 코드는 그대로 동작합니다.

- **기온 페이지(203곳):** 목록 위에 검색 칸이 나옵니다. 이름이나 코드 일부로 좁힐 수 있고("광주" → 2곳), 같은 이름은 코드로 구분합니다.
- **육상·해상·전망 페이지, 발표시각:** 항목이 적어서 검색 없이 목록만 보여 줍니다.
- **키보드:** 방향키·Home·End·PageUp/Down으로 이동, Enter로 선택, Esc로 닫기. 닫힌 상태에서는 글자를 입력해 이동할 수도 있습니다.
- **스크린리더:** `combobox`/`listbox`/`option` 역할과 선택·펼침 상태를 제공하고, 이름은 "지역 선택 + 현재 선택값"으로 읽힙니다.
- **모바일(폭 640px 이하):** 화면 아래에서 올라오는 선택창(바텀시트)으로 열립니다. 배경을 누르면 닫히고, 검색 칸 글자는 16px이라 iOS에서 자동 확대되지 않습니다.
- 펼침 효과는 '동작 줄이기' 설정을 켜면 적용되지 않습니다.

## 날짜·시각 표기 규칙

화면 전체에서 아래 세 가지 형식만 씁니다.

| 종류 | 형식 | 예 |
|---|---|---|
| 예보 날짜 | `월/일(요일)` | `11/15(일)` — 카드·그래프 축·표·말풍선 모두 동일 |
| 발표시각 | `월/일(요일) 시각` | `11/11(수) 06시 발표` — 드롭다운과 상태 칸 |
| 확인 시각 | `시:분:초` (오늘이 아니면 날짜 추가) | `14:06:55` |

- 한 정보는 한 곳에만 둡니다. 발표시각은 드롭다운(선택)과 상태 칸(`8시간 전 발표` 같은 경과 시간)에만 나오며, 결과 위 칩에서는 뺐습니다. '마지막 성공 조회'와 '마지막 확인'은 한 칸으로 합치고 자료 출처를 보조 줄로 보여 줍니다.
- 원본 발표시각 코드(`tmFc` 202611110600)와 전체 날짜는 '조회 정보 자세히' 안에서만 확인합니다.

## 중기전망 요약 규칙

전망문은 글이 길어서 읽기 어렵기 때문에, 문장을 바꾸지 않고 **원문에 이미 적힌 값만** 뽑아 맨 위에 3줄로 요약합니다(`static/outlook-parse.js`). 칩 대신 아이콘·라벨·줄맞춤한 글자로 보여 줍니다.

- **비:** `11/15(일) 오전 전국 · 11/16(월) 강원영동 · …` 처럼 날짜와 지역 이름을 원문 글자 그대로 나눕니다.
- **기온:** 날짜 범위별로 `아침 6~14℃ · 낮 12~19℃`와 평년 비교 표현(`평년과 비슷하거나 조금 높음` 등 정해진 표현일 때만). 숫자 하나라도 찾지 못하면 요약하지 않습니다.
- **해상:** 날짜·해역, 파고 범위(`1.0~4.0m`)와 원문 수식어(`매우 높게`).
- **날짜:** 원문의 `15일(일)`에는 월이 없으므로, 발표일 전후에서 **일과 요일이 모두 맞는 날**을 찾아 `11/15(일)`로 바꿉니다. 맞는 날이 없으면 월을 짐작하지 않고 원문 표기를 씁니다.
- **자세히 보기:** 요약에 담기지 않는 주제(주말전망, 변동성 등)는 한 줄씩 나열하고 눌러서 원문을 봅니다. 같은 이름의 주제가 여럿이면 첫 날짜를 붙여 구분하고, 변동성·유의·주의 주제에는 '유의' 표시를 붙입니다. 맨 아래에서 원문 전체도 볼 수 있습니다.
- 요약할 수 있는 문장 형태가 아니면 요약 없이 원문을 펼쳐 보여 줍니다. 요약은 원문을 대신하지 않으며, 수치 그래프로 바꾸지 않습니다.
- 테스트: `tests/outlook_parse.test.mjs`(Node 필요, 없으면 건너뜀)가 실제 전망문 2건으로 값이 원문에 그대로 있는지, 월 변환, 해석 불가 문장 처리를 검증합니다.
