# 자동 갱신·호출량 관리

> 기상청 API 호출 정책, 캐시, 여러 서버 구성, Gemini 도우미 설정 · [← README로 돌아가기](../README.md)

## 자동 갱신과 호출량 관리

- 중기예보는 **하루 두 번(06:00·18:00 KST)** 발표됩니다. 30초마다 새 예보가 생기는 것이 아니라, 활성 탭이 30초마다 같은 발표본을 서버에 다시 확인합니다.
- 브라우저 → 로컬 서버 → 기상청 API 순서입니다. 브라우저는 기상청에 직접 요청하지 않습니다.
- 같은 기능·지역코드·발표시각·페이지·응답형식(JSON) 요청은 서버 캐시(30초)를 공유하고, 동시에 들어오면 외부 요청 하나로 합칩니다.
- **중기 네 기능 전체** 외부 호출 사이에 최소 30초 간격을 둡니다. **단기 세 기능**은 별도 그룹으로 최소 5초 간격을 둡니다(같은 지역 격자의 새 발표본은 어차피 몇 분~몇 시간에 한 번이라 캐시를 길게 씁니다). 따라서 탭을 몇 개 열어도 외부 호출은 24시간 최대 2,880회입니다(참고: 기능마다 따로 30초 호출하면 11,520회로 일일 허용량 10,000회를 넘습니다).
- 순서를 기다리는 페이지는 파란 "조회 대기 중" 안내를 보여 주고, 서버가 알려 준 시간 뒤 자동 조회합니다. 이미 자료가 있는 페이지는 자료가 없는 페이지에 순서를 양보하고 캐시 자료를 보여 줍니다.
- 숨긴 탭에서는 자동 확인을 멈추고, 페이지를 떠나면 타이머를 정리합니다. 수동 "지금 확인"도 같은 캐시와 간격을 적용합니다.
- 성공·실패·재시도·이전 발표본 확인 등 **모든 외부 요청**을 `runtime/gateway.sqlite3`에 기록합니다(서버 재시작 후에도 유지).
- 단기 기능의 서버 캐시는 현재 날씨·6시간 예보 10분, 단기예보 30분입니다(발표본마다 값이 정해져 있고 실황·초단기예보는 10분마다 갱신). 화면은 30초마다 서버에 확인하지만 대부분 캐시에서 답합니다.
- 일일 허용량 10,000회는 이 키의 중기·단기 일곱 기능 합산으로 봅니다. 앱 자체 상한은 **9,000회**, **8,000회**부터 화면 상단과 터미널에 관리자 경고를 표시합니다. 상한에 도달하거나 제공기관이 호출 제한(코드 22)을 반환하면 외부 호출을 멈추고 캐시 자료와 마지막 성공시각만 보여 줍니다.
- 공공데이터포털의 일일 집계 초기화 시각은 공식 자료에서 확인하지 못했습니다. 그래서 더 보수적인 **최근 24시간 이동 집계**를 사용합니다.
- 같은 인증키를 다른 프로그램에서도 쓰면 이 앱의 집계와 포털 집계가 다를 수 있습니다.
- 오류가 반복되면 같은 조건의 재시도 간격을 30초 → 60초 → 120초 … 최대 15분으로 늘립니다.

### 여러 서버 구성

- 같은 PC에서 같은 `runtime/gateway.sqlite3`를 쓰는 서버 프로세스들은 호출 간격·호출량·캐시를 공유합니다(SQLite 잠금으로 호출 슬롯 예약).
- **다른 PC에 서버를 여러 대 두는 구성은 지원하지 않습니다.** 그런 경우 이 서버 하나를 중앙 API 게이트웨이로 두고 다른 곳에서는 이 서버만 호출하세요.

## Gemini AI 예보 도우미 (선택)

모든 페이지 우측 하단의 `AI 예보 도우미`에서 한국어로 페이지 이동, 공식 지역 선택, 최근 24시간 발표본 선택, 예보 새로고침, 현재 조회 자료 설명을 요청할 수 있습니다. 사용하려면 `KEY.env`에 다음 줄을 추가하고 서버를 재시작합니다(없어도 예보 기능은 정상 동작).

```text
GEMINI_API_KEY=Google_AI_Studio에서_발급받은_실제_키
GEMINI_MODEL=gemini-3.8-flash
```

- 브라우저는 `/api/chat`만 호출하고 Gemini 키는 서버에서만 사용합니다. Gemini가 제안한 동작은 서버·브라우저 허용목록을 모두 통과해야 실행됩니다.
- 현재 예보 설명은 서버 캐시를 기능·지역·발표시각으로 재검증한 뒤 필요한 자료만 전달합니다.
- 기상청 호출 정책과 분리되어, 메시지를 보낼 때만 호출합니다. 앱 자체 상한은 분당 8회, 최근 24시간 200회입니다. 질문 원문과 키는 기록하지 않습니다.
- Google의 실제 한도와 요금은 계정마다 다르므로 Google AI Studio에서 확인하세요. 참고: [모델](https://ai.google.dev/gemini-api/docs/models), [함수 호출](https://ai.google.dev/gemini-api/docs/function-calling), [호출 한도](https://ai.google.dev/gemini-api/docs/rate-limits).
