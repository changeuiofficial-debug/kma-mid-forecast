데이터 안내

중기예보는 하루 두 번(06:00·18:00 KST) 발표됩니다. 30초마다 새 예보가 생기는 것이 아니라, 활성 탭에서 30초마다 같은 발표본이 바뀌었는지 서버에 확인합니다. 숨긴 탭에서는 자동 확인을 멈춥니다.

브라우저는 이 로컬 서버에만 요청합니다. 서버가 기상청 API 호출, 같은 조건의 캐시 공유, 네 기능 합산 호출량, 외부 호출 사이 최소 30초 간격을 관리합니다. 그래서 탭을 여러 개 열어도 외부 호출은 24시간 최대 2,880회입니다.

호출량은 최근 24시간 이동 집계입니다(공공데이터포털의 일일 초기화 시각은 공식 자료에서 확인하지 못했습니다). 8,000회부터 경고하고 9,000회에서 외부 호출을 멈춥니다. 같은 인증키를 다른 프로그램에서도 쓰면 포털 집계와 다를 수 있습니다.

지역코드는 기능마다 따로 관리합니다(전망 stnId, 육상 regId, 기온 regId, 해상 regId). 행정동 단위 예보가 아니며, 육상 지역과 해역을 자동으로 연결하지 않습니다.
